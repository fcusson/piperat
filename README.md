# Piperat 🐀

> Your pipelines' tiny guardian!

> [!NOTE]
> Work in Progress — Piperat is still in early development! Features, interfaces, and behaviors are subject to change.

Piperat lets you monitor your CI/CD pipelines (Bitbucket, GitHub, GitLab) right from your terminal — with a slick TUI and optional Neovim integration!

Catch build failures, track progress across parallel steps, and celebrate success — all without ever leaving your terminal.

> [!TIP]
> Goals
>
> 🛠️ Smart and easy setup (auto-detect git providers).
> 🎨 Support for both NerdFont and standard terminal fonts.
> 🚀 Lightweight and fast feedback loop.
> 📦 Extendable for Neovim native integration later.


> Your code runs the maze. Piperat watches the exits.

## 📖 Project Vision

> [!QUOTE]
> Build a lightweight, fast, and charming TUI to monitor pipelines directly from the terminal, with smart integrations and a playful attitude.
>
>Piperat is designed for developers who live in their terminal or Neovim, offering real-time insights into builds, tests, and deploys — without the clutter.

### Key principles:

- Terminal-first, distraction-free experience.
- Multi-provider support (Bitbucket Pipelines, GitHub Actions, GitLab CI/CD).
- Friendly UX: clear progress visualization, errors made obvious.
- Easy setup: minimal config, smart defaults, provider autodetection.
- Extendable: built with a future Neovim plugin integration in mind.
